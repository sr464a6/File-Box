FileBox
=======
Cara pakai:
1. Buka index.html langsung di browser (double click), atau host di server statis apa saja.
2. "Tambah Navbar" untuk bikin kategori baru — ikon otomatis muncul sesuai kata yang diketik (contoh: ketik "IT" -> ikon laptop).
3. Navbar custom bisa digeser (drag) untuk diurutkan ulang, posisinya tetap terkunci di dalam kotak sidebar.
4. Klik navbar lalu "Tambah File" untuk upload file ke kategori itu.
5. "Beranda" menampilkan file yang baru dibuka. "Semua File" = semua file. "Favorit" = file yang ditandai bintang.
6. "Compress" untuk convert PDF -> Word atau Word -> PDF, diproses langsung di browser (butuh koneksi internet karena memuat library dari CDN).

Data disimpan di localStorage browser kamu masing-masing (bukan server), jadi tiap browser/perangkat datanya beda.
